# Little Island

An offline collection of games, learning activities and island discoveries for children and families. Built with Expo SDK 57, React Native and TypeScript for iPhone, iPad and web.

Play board and card classics, explore mazes, practice reading and numbers, discover science and CHamoru words, race through island arcades, and decorate a home with an islander of your own. Play solo or pass one device around. Supported Apple devices can also join grown-up-approved nearby mystery rooms.

## Privacy

No ads, accounts, tracking, purchases or cloud sync. Games, spoken help and progress work offline. Saves stay on the device; deleting the app can remove them. Backups can include player names and secret game roles, so keep them private. Nearby play uses a local connection between approved devices. The source-code link is behind the grown-up gate and opens an external browser only when requested.

## Run and test

Use Node 22.13 or newer, npm, and Python 3 (the audio-manifest tests use the standard library).

```sh
npm ci
npm start
npm run check
npm run doctor
```

Metro uses port 43820. For a static web preview:

```sh
npm run export:web
npm run preview
```

Preview uses port 43821; set LITTLE_ISLAND_PORT to override it. Stop the process with Ctrl-C. The full check runs TypeScript, ESLint, Vitest and the web export. To limit test workers: `VITEST_MAX_WORKERS=2 npm run check`.

The app uses Expo Router. Screens are in `src/app`, pure game engines and save validation are in `src`, and regression tests are in `tests`. Native nearby play is implemented in `modules/island-nearby`; it requires an Apple development build and is unavailable in Expo Go and web. Native project folders are generated by Expo and are not checked in. Configure your own application identifiers, signing team, EAS project and store submission account before building for distribution. Test on physical devices before making a release.

## Contributing

Small fixes, accessibility improvements and regression tests are welcome. Keep play family-friendly, reading untimed and saves backward compatible. Use the same pure rules for hints and moves. Explain the change and how you tested it; avoid submitting personal saves, names, screenshots of children, credentials or model weights. CHamoru language changes need a reliable source and language review.

A clean source snapshot can be made with `npm run export:public -- /path/to/new-directory`. The exporter refuses an existing target and checks privacy, known credential patterns and every audio hash before writing the final tree. Review new content before publishing; automated guards cannot identify every possible personal note or secret.
